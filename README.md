# Engelsiz Akıllı Şehir Haritası 🌍

Bu proje, engelli bireylerin şehir içinde bağımsız, güvenli ve erişilebilir şekilde hareket etmelerini kolaylaştıran bir akıllı harita uygulamasıdır.

## 🎯 Amaç
Şehirdeki rampalar, yokuşlar ve engelleri tespit ederek kullanıcıya sesli veya titreşimli bildirimlerle uyarı verir. Böylece engelli bireylerin şehirde özgürce hareket etmesi sağlanır.

## ⚙️ Teknolojiler
- React + Leaflet (harita arayüzü)
- Google Maps API veya OpenStreetMap
- Text-to-Speech API (sesli bildirimler)
- Firebase (veri depolama)

## 🚀 Özellikler
- Gerçek zamanlı konum takibi  
- Erişilebilirlik noktalarının görüntülenmesi  
- Sesli uyarı sistemi  
- Topluluk katkılı engel bildirimi
